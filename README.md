# Spoon Manager

Spoon の公式APIでコメントを受信し、読み上げ、集計、質問受付、投票、ゲーム、自動応答を行うWindowsアプリです。C++20 / Win32 / WebView2を使用します。

## ダウンロードと起動

[GitHub Releases](https://github.com/sasamina3337/spoon-manager/releases) から Windows x64 向けの配布物を取得してください。

| 配布物 | 使い方 |
| --- | --- |
| `SpoonManager-2.9.0-win64-Setup.exe` | 1ファイルのインストーラー。実行してインストールします。 |
| `SpoonManager-2.9.0-win64.zip` | 全体を展開し、フォルダー内の `SpoonManager.exe` を起動します。 |
| `SHA256SUMS.txt` | ダウンロードしたインストーラーと ZIP の SHA-256 一覧です。 |

どちらも [Microsoft Edge WebView2 Evergreen Runtime（x64）](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) が必要です。インストーラーは未導入なら案内して終了し、ランタイムの自動インストールは行いません。

アプリ本体は画面ファイル、DLL、Cloudflare の補助 EXE と一緒に動作します。`SpoonManager.exe` だけを取り出して実行する形式にはしていません。ZIP はフォルダー構成と `licenses/` を保持してください。配布物には認証情報、設定、利用記録、開発用依存、Debug DLL を含めません。

Spoon の開発者登録・API 認証設定は各利用者が用意してください。音声サービスや外部 API の利用条件は [サードパーティーと外部サービス](THIRD_PARTY_NOTICES.md) を参照してください。

## 内蔵音声とクレジット

「設定 → 読み上げ」で「内蔵VOICEVOX（オフライン）」を選ぶと、VOICEVOX本体の別途インストール・起動なしで合成できます。既定では32キャラクターとVOICEVOX Nemoの9音声、計92スタイルを利用できます。「追加許諾が必要な音声を避ける」をOFFにすると、10キャラクターの公式規約リンク・注意点と利用区分の確認画面を表示します。「個人・非商用」または「必要な連絡・許諾を対応済み」を選択し、条件と規約への同意後に候補を選んで設定を保存すると計132スタイルを利用できます。商用・法人等で必要な連絡・許諾は音声をその用途で使用する利用者が対応してください。この画面自体が権利者の許諾を与えるものではありません。個人利用でも収益や用途によって許諾が必要です。設定をONへ戻すか確認版が古くなった場合は追加音声を利用できません。初回利用時と確認版の更新後は、通常の規約とクレジットの確認欄にもチェックして保存してください。外部エンジンの条件は別途確認してください。

音声ごとのクレジットは設定画面と[サードパーティー表示](THIRD_PARTY_NOTICES.md)に記載しています。立ち絵・キャラクター素材は同梱していません。音声のみの利用と、立ち絵や設定等を用いる二次創作とでは許諾範囲が異なります。

配信・録画には、設定画面の「音声クレジット・利用規約」から表記をコピーして、視聴者が確認できるプロフィール・概要欄等へ掲載してください。個別規約の用途制限も適用されます。[採用・保留モデルと規約](licenses/VOICEVOX-MODEL-REVIEW.md)を参照してください。COEIROINKは再配布条件により同梱せず、別途導入した本体のAPIへ接続します。

「クレジットを自動送信する」は既定ONです。読み上げが有効な配信では、入室あいさつの直後に `クレジット：` / `VOICEVOX:ずんだもん、No.7` のようにエンジン別にまとめて投稿します。100文字を超える場合だけ分割し、必須CV名や特殊な指定表記を省略しません。その配信で割り当てた音声と通知用音声を累積し、退室・声変更後も配信終了まで残します。同じ配信へ再接続・アプリ再起動した場合も履歴を保持し、別の配信では新しく集計します。手動・`/voice` による声の変更時と通知用音声の変更時にも、変更先のクレジットを送信します。同じ音声への一括変更は通知をまとめます。1回の投稿が20コメントを超える場合や、不正な制御文字を含む場合は送信前に中止し、自動コメントの状態表示に確認を促すエラーを出します。

自動クレジットは入室あいさつやコマンド応答のON/OFF・自動コメントの一時停止とは別に動作します。リスナーへ音声を流さない場合は、読み上げ設定で自動クレジットをOFFにできます。OFF中は警告を表示し、割り当て履歴は引き続き保持します。チャット送信の機能・DJの同意と入室イベントの受信が必要です。APIの制限や切断等で送信できなかった場合は自動コメントの状態表示を確認してください。コメント表示だけで全音声の規約を満たすと保証する機能ではありません。特にCOEIROINKはコンテンツ内またはコンテンツ概要欄への表記を指定しているため、プロフィールだけでよいと一律には扱わず、各規約の掲載場所にも従ってください。

モデル・辞書・DLL・ライセンスを含む `voicevox/` を実行ファイルと一緒に保持してください。VVMは共通規約のアプリ組み込み再配布許諾に基づき同梱します。利用者による別ダウンロードは必須ではなく、別配布にしても生成音声の利用条件は同じです。27個のVVMを含む音声データは約1.66GiBです。初回の開発ビルドでは固定ハッシュを照合して必要なデータを取得し、以後はキャッシュを利用します。

## 開発環境

Windows x64、Visual Studio 2026 の Microsoft C++ Build Tools（C++ によるデスクトップ開発）、Windows SDK、CMake 4.2 以降が必要です。windows-debug / windows-release は Visual Studio 2026 のジェネレーターを使用します。起動には Microsoft Edge WebView2 Evergreen Runtime が必要です。

## VS Code

推奨拡張の C/C++ と CMake Tools を有効にしてください。フォルダーを開くと CMake が構成され、選択中のプリセットのヘッダー、定義、コンパイルオプションが IntelliSense に渡されます。

- F5: Debug をビルドしてデバッグを開始します。
- Ctrl+Shift+B: Debug をビルドします。
- テストエクスプローラー: CTest で検出されたテストを実行します。初回はビルドが必要です。
- 「タスクの実行 → テスト」: Debug ビルド後にテストを実行します。
- 「タスクの実行 → Release ビルド」: 配布用の構成をビルドします。

設定は [.vscode](.vscode/)、構成は [CMakePresets.json](CMakePresets.json) にあります。windows-debug / windows-release を選択できます。

## コマンド

PowerShell で実行します。

~~~powershell
.\spoon.ps1 build
.\spoon.ps1 test
.\spoon.ps1 start
.\spoon.ps1 build --debug
.\spoon.ps1 start --debug
~~~

既定は Release です。build はアプリとインストーラーを作成し、dist/spoon-manager/ に配布ファイルを配置します。実行ファイルは SpoonManager.exe、インストーラーは dist/installers/SpoonManager-2.9.0-win64-Setup.exe です。実行ファイルと ui/、ランタイム DLL を一緒に配置してください。

JavaScript の画面ロジックをテストするときだけ Node.js が必要です。

~~~powershell
npm ci
npm run test:ui
~~~

アプリのビルド・起動にはNode.jsは不要です。一時参加URLの公開に使うCloudflareの実行ファイルは、固定バージョンとSHA-256を検証して同梱します。

Release 構成では、インストーラーに使用した同じ配布用ファイルから `dist/releases/SpoonManager-2.9.0-win64.zip` も作成します。第三者のライセンスと NOTICE も両方に同梱します。

## 機能と保存データ

テーマは「設定 → 表示」で選択でき、即時反映・自動保存されます。「設定 → コマンド」では各コマンドを個別に ON／OFF にして「設定を保存」で反映できます。OFF のコマンドは処理と返信を停止し、ヘルプ一覧にも保存済みの状態を表示します。

受信開始時に、すべてのSpoon API権限の同意をまとめて確認します。既存の同意に不足がある場合は同意画面を開き、完了後に受信を自動開始します。開発者センターにも全権限を登録してください。必要な権限の一覧は「設定 → 連携 → 開発者センターに登録する権限」に表示します。各機能のON/OFFは同意と独立して設定できます。

リダイレクトURIは `http://localhost:17864/oauth/callback`（ポートを変更した場合はその値）です。認証後のアプリへの復帰と認証タブの自動閉鎖は「API連携・起動時の設定」で指定でき、既定で有効です。ブラウザーが自動閉鎖を許可しない場合は、認証完了画面からタブを閉じてください。

対応機能は [FEATURES.md](FEATURES.md)、コマンドの対応状況は [COMMANDS.md](COMMANDS.md)、構成と検証方法は [開発ガイド](native/README.md) を参照してください。

設定と記録の保存先は互換性のため従来どおり %APPDATA%/Spoon Manager Desktop/ です。起動時の --data-dir で変更できます。認証情報や保存データは配布物へ含めません。
